HOUSE OF LOST YOUTH — MOBILE V2 + LIVE LEADERBOARD

UPLOAD:
1. Log in to Netlify.
2. Open the existing HOUSE OF LOST YOUTH project.
3. Go to Deploys and drag THIS ENTIRE UNZIPPED PROJECT FOLDER into the deploy dropzone.
   Important: upload the project root, not just the public folder.
4. Netlify will install @netlify/blobs and deploy the /api/leaderboard function.

LIVE LEADERBOARD:
- Finishing the game opens a name form.
- Submitting saves the player to a shared Netlify Blobs leaderboard.
- Everyone sees the same leaderboard.
- Ranking is by final game score.
- After submission the board stays visible, then POSTHUMAN opens after 10 seconds.
- Players can tap LISTEN TO POSTHUMAN immediately.

MOBILE:
- Controls are fixed BELOW the game in portrait mode.
- Larger D-pad and action buttons.
- SING is larger and easier to hit.
- Native text selection/callout is disabled on the play controls.
